# E-Commerce Website Manual Testing Project

## Project Overview
This project focuses on manual testing of an e-commerce website to verify core functionalities, identify defects, and ensure a smooth user experience.

## Objectives
- Understand the Software Testing Life Cycle (STLC).
- Design and execute positive and negative test cases.
- Validate login, product selection, shopping cart, and checkout functionality.
- Document defects with steps to reproduce, expected results, and actual results.
- Prepare test execution and summary reports.

## Scope of Testing
- Login and logout
- Product listing and sorting
- Add to cart and remove from cart
- Checkout and order information
- Input validation and error messages

## Testing Types
- Functional Testing
- Positive and Negative Testing
- Smoke Testing
- Regression Testing

## Tools Used
- Manual Testing
- Microsoft Excel
- GitHub
- Web Browser

## Project Deliverables
- Test Plan
- Test Scenarios and Test Cases
- Bug Report
- Test Execution Report
- Test Summary Report

## Project Status
In progress — test cases, execution results, and defect reports will be added as testing is performed.
