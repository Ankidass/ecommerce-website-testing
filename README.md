# E-Commerce Website Manual Testing Project

A manual QA portfolio case study for a demo e-commerce store, covering login, product listing, cart, checkout, navigation, and basic usability/input validation.

## Project Objectives
- Design structured test cases with clear preconditions, steps, and expected results.
- Cover positive and negative scenarios across core user journeys.
- Demonstrate test execution logging and defect-report documentation.
- Organize testing artifacts in a recruiter-friendly GitHub repository.

## Test Environment
- Demo application: [SauceDemo](https://www.saucedemo.com/)
- Test approach: Manual functional, negative, usability, and basic validation testing.
- Use only public demo credentials and non-sensitive test data.

## Project Files
- `Ecommerce_Website_Test_Cases.xlsx` — test case inventory.
- `Ecommerce_Bug_Report_Template.xlsx` — defect-report format and illustrative examples.
- `Test_Execution_and_Results.xlsx` — execution-log example and defect documentation examples.
- `Test_Summary_Report.md` — scope, workflow, and project summary.

## Test Coverage
Login/logout, product listing/details, cart, checkout validation, order confirmation, navigation, keyboard navigation, responsive viewport checks, and safe input handling.

## Reporting Notes
Execution workbook entries are explicitly presented as sample data for portfolio demonstration. Replace sample observations with your own recorded results before claiming a personally executed test run. Defect examples are illustrative and should not be represented as confirmed bugs unless reproduced.
